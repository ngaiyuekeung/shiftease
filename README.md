# 排班

给轮班的人用的日历。这是网页原型，先把排班和看班试顺，再考虑写成 iOS App。

## 跑起来

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。把窗口收成手机宽度，最接近以后的 App。

排过的班存在这台浏览器里，刷新还在。

## 现在能做的

- 刷班：选一个班，按住日期划过去
- 循环：按顺序组成一轮，排到月底，或排满 4 周
- 今天和明天：什么班、几点到几点、上几小时、离下班还有多久
- 班次自己定：名称、时间、颜色。RDO、AL 这种叫法可以直接用
- 备注：写成 #标签，没有就不显示

点黑背景会取消选中，并回到这个月。左右滑日历只是在看，上面两张卡始终是今天和明天。

上班提醒、桌面小组件、工时统计、数据备份，还没做。
